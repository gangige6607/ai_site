# 국악 타악 연주가 방승환 공식 웹사이트

국악 타악 연주가 방승환의 전문성과 경력을 소개하고, **사물놀이 강의 문의, 국악 공연 섭외, 문화예술 교육, 기관 및 예술가 협업 제안**으로 이어지도록 제작된 전문 예술가 포트폴리오 웹사이트입니다.

빌드 프레임워크나 복잡한 설치 과정 없이, **Windows 환경에서 `index.html` 파일을 더블 클릭하여 웹 브라우저에서 바로 확인**할 수 있습니다.

---

## 1. 실행 방법

1. 본 폴더에 있는 **`index.html`** 파일을 마우스로 더블 클릭합니다.
2. Chrome, Edge, Whale 등 기본 웹 브라우저에서 웹사이트가 즉시 열립니다.
3. 별도의 로컬 웹 서버 실행이나 npm 설치가 전혀 필요 없습니다.

---

## 2. 프로젝트 파일 구성

```text
web3/
├── index.html        # 메인 웹페이지 구조 (시맨틱 HTML5, 접근성, SEO 메타태그)
├── style.css         # 디자인 시스템 (모던 한국적 미학, 반응형 그리드, 모달 스타일)
├── data.js           # 사이트 데이터 관리 파일 (프로필, 경력, 교육, 갤러리, 연락처)
├── app.js            # 웹사이트 인터랙션 (렌더링, 갤러리 라이트박스, 문의 폼 로직)
└── README.md         # 프로젝트 안내 및 사용자 수정 가이드 (본 문서)
```

## 3. 수정해야 할 정보 목록 및 수정 방법 (`data.js`)

본 사이트는 HTML이나 CSS 코드를 직접 건드릴 필요 없이, **`data.js` 파일만 메모장이나 에디터로 열어 수정**하면 사이트 전체에 즉시 반영됩니다.

### ① 연락처 및 공식 이메일 (`contactInfo`)
`data.js` 파일 상단의 `contactInfo` 섹션에서 수정합니다:
```javascript
contactInfo: {
  email: "실제이메일@domain.com",       // 문의가 발송될 공식 이메일 주소
  phone: "010-XXXX-XXXX",               // 공식 연락처
  location: "대한민국 서울특별시 / 전국 출강 가능",
  kakaoChannel: "카카오톡채널주소",      // 있을 경우 입력
  youtubeChannel: "유튜브채널주소"       // 있을 경우 입력
}
```

### ② 경력 타임라인 (`careerTimeline`)
확인되지 않은 이력은 임의로 지어내지 않고 `[편집 안내]` 자리표시자로 구성되어 있습니다.
실제 경력에 맞게 `data.js`의 다음 항목들을 수정하십시오:
- **확인된 공식 이력**: KBS 국악관현악단 타악 연주자 정년퇴직, 국악 사물놀이·타악 전공 박사(Ph.D)
- **추가 권장 이력**:
  - `year`: 실제 연도 (예: "2018년 ~ 2023년")
  - `title`: 실제 공연/출강 명칭 (예: "국립극장 사물놀이 대축제 초청 협연", "00대학교 국악과 사물놀이 실기 지도")
  - `confirmed`: `true`로 변경하시면 녹색 '공식 확인 이력' 뱃지로 바뀝니다.

### ③ 활동 갤러리 사진 및 유튜브 영상 (`gallery`)
현재는 안내용 전통 엠블럼 그래픽이 표시되고 있습니다. 실제 사진이나 영상을 넣으시려면:

1. **실제 사진 등록 시**:
   - 사진 파일을 같은 폴더 내(예: `photo1.jpg`)에 넣습니다.
   - `data.js`의 `gallery` 배열에서 해당 카드의 `imageSrc` 값을 변경합니다:
     ```javascript
     imageSrc: "photo1.jpg"  // 지정하면 그래픽 대신 실제 사진이 표시됩니다.
     ```
2. **유튜브 영상 등록 시**:
   - 본인의 유튜브 영상에서 **[공유] -> [퍼가기(Embed)]** 주소를 복사합니다.
   - `videoUrl` 값을 변경합니다:
     ```javascript
     videoUrl: "https://www.youtube.com/embed/실제영상아이디"
     ```

## 4. 문의 폼(Contact Form) 작동 방식 및 외부 연동 안내

### 현재 동작 방식 (클라이언트 PC 전용)
- 방문자가 문의 폼을 작성하고 **[문의 내용 접수 및 전송하기]**를 누르면:
  1. 입력값(이름, 연락처, 문의 내용, 개인정보 동의)을 검증합니다.
  2. 백엔드 서버 없이 전송된 것처럼 속이지 않고, **정직한 안내 모달**이 뜹니다.
  3. **[✉️ 내 기본 이메일 프로그램으로 바로 보내기]** 버튼을 누르면 사용자 PC의 기본 메일 프로그램(Outlook, 기본 메일 등)이 열리며 수신자, 제목, 작성한 문의 내용이 자동으로 입력됩니다.
  4. **[📋 문의 내용 전체 복사하기]** 버튼을 누르면 클립보드에 복사되어 카카오톡, 문자 등에 바로 붙여넣을 수 있습니다.

### 추후 무료 외부 폼 서비스(Formspree 등) 자동 수신 연동 방법
웹 호스팅에 업로드 후 문의 내용을 본인 이메일로 자동 전송받고 싶으신 경우:
1. [Formspree](https://formspree.io/)에 무료 회원가입 후 폼 ID(`https://formspree.io/f/XXXXXX`)를 발급받습니다.
2. `index.html` 파일의 `<form id="contact-form">` 태그를 다음과 같이 변경하시면 됩니다:
   ```html
   <form id="contact-form" action="https://formspree.io/f/발급받은ID" method="POST">
   ```

## 5. 디자인 및 기능적 특징

1. **모던 한국적 미학 (Modern Korean Aesthetics)**:
   - 짙은 먹색(Ink Black `#111215`), 따뜻한 한지 아이보리(`#fbfaf6`), 전통 금빛 포인트(`#c59b48`)를 조화롭게 사용하여 격조 높은 전통 예술가의 위상을 구현했습니다.
2. **완벽한 반응형 (Responsive)**:
   - 스마트폰, 태블릿, 데스크톱 화면 크기에 맞춰 최적화된 레이아웃과 모바일 전용 햄버거 메뉴를 지원합니다.
3. **스마트 문의 연동**:
   - 교육 프로그램 카드와 협업 카드의 **[문의하기]** 버튼을 누르면 하단 문의 섹션으로 부드럽게 이동하며, 선택한 프로그램명이 문의 내용에 자동으로 채워집니다.
4. **접근성 및 SEO**:
   - 시맨틱 HTML5 태그, 네이버/구글 검색 최적화 메타태그, Open Graph 소셜 미리보기 태그를 완비했습니다.
